Publish to GitHub

Your app data is saved in your browser. To make it live on the User Store, paste it into the GitHub editor.

  • Step 1: Click "Copy Data" — JSON is copied to clipboard
  • Step 2: Click "Open GitHub Editor" — it opens the data file
  • Step 3: In GitHub: select all, paste, click "Commit changes"
  • Step 4: User Store updates instantly (may take 1-2 min cache)
